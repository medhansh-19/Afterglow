# Windows feature-parity audit

The reference is the current macOS source, including local clock, collection, screenshot-companion and energy changes. The Windows port reuses the Linux renderer and the shared Swift lyric engine; this is a **development preview**, not a claim that every Mac function is present or validated on Windows.

“Shared tested” means automated domain or Chromium UI checks passed. It does not establish WebView2 or Windows-native behavior. Native evidence is recorded separately in [VALIDATION.md](VALIDATION.md).

| Mac behavior | Windows implementation and evidence | Remaining acceptance or gap |
|---|---|---|
| Connect Spotify and Apple Music without credentials | Windows Global System Media Transport Controls discovery, selected-session metadata and transport; ambiguous IDs are rejected | Real Windows Spotify and Apple Music desktop sessions, metadata/seek/unsupported-control behavior need runtime tests |
| Monotonic progress, pause, seeking, previous/next/stop | SMTC timeline age and rate correction plus shared interpolation; domain pause/backward-seek tests | Real-player stale timeline and transport checks |
| Provider fallback, recording match, cache, imported overrides | Same Swift `AfterglowCore` and JSON sidecar as Mac; shared service tests cover LRC/enhanced LRC/YAML/TXT and errors | Clean installed Windows helper/runtime and live provider checks; bounded 15/45-second missing-synced retries have fake-timer tests |
| Untimed text stays in explicit library | Shared listener graph never displays untimed text; provider diagnostics confined to library | Browser checks and code review; provider-specific real runtime input remains to check |
| Supplied word times and opt-in estimates | Prepared display tokens preserve original intervals; group subdivision only with estimates enabled; domain regressions | Visual comparison against Mac with long/RTL/multilingual songs |
| Bounded 24-word pages, punctuation and brackets | Shared prepared-line cache, paging and index mapping; tests mirror Mac punctuation, decimal, ellipsis and joined-token cases | WebView2 font/layout comparison |
| Instrumental and long-gap ribbons | Instrumental markers and sparse line-only holds yield to waves; timestamp-based provided intervals remain authoritative | Tiny breath transitions and exact Mac wave-opacity choreography differ |
| Chorus arrangements and backward seeking | Repeated substantial passage analysis cached per document; canonical line/page seeds; tests distinguish isolated filler | Visual comparison with Mac deterministic column layout; renderer is a port, not identical Swift drawing |
| Album-colored glow and artwork | Bounded local SMTC thumbnail read, palette extraction, manual hex and saved swatches | Real artwork, failures, track switches and protected-player cases |
| Presets, named colors and color wheel | Expanded Mac preset palette, named/editable RGB swatches with deduplication, native HTML color control; domain/browser checks | Embedded Mac hue/saturation wheel is replaced by the operating system color picker; native Windows picker acceptance remains |
| Markers and custom emoji | Seven shared marker types with native text input; browser exercises all variants | Windows emoji/font rendering and complete grapheme comparison |
| Independent wallpaper image copies | Locally encoded image in atomic library; size-bounded import | Native chooser and large/unsupported image checks |
| Seven clock styles, color/date/seconds/format/scale | Shared clock renderer and controls, 70–140% scale with migration; browser exercises all seven styles | Real song Appearance preview includes clock settings; Mac-style clock gallery and independent dedicated editor differ; native locale/12–24-hour matrix still needed |
| Per-song scenes and reset | Recording identity, appearance-only snapshots, remove/update; providers remain global; domain and browser tests | Real song changes/restarts; Mac exact baseline-reset semantics need comparison |
| Collections, favorites, membership and precedence | Unique 1–40-character names, rename, membership/source cleanup, explicit inheriting membership and confirmed delete; regression/browser tests | Album cover, preset/saved/custom modes and shared current-song preview implemented; native cross-song comparisons remain; Mac two-column selected-collection layout differs |
| Collection colors editable from Appearance | Active colored collection's hex tint binding stays scoped to that collection | Album/default/collection bindings need native real-song comparison; edits and preset application stay scoped to the active collection |
| Lyrics alternatives and per-recording timing | Shared library UI, timing range, alternative line selection | Manual alternative documents persist per recording and stop automatic retries; Use online lyrics clears imports/manual selection; real provider alternatives still need acceptance |
| Lyric excerpts, saved cards, PNG export/copy | Six-line/280-character limits; saved original metadata/color; 1080×1350 PNG; browser validates dimensions/persistence | Installed Windows image clipboard and native Save dialog acceptance |
| Frozen lyric map save/copy | Current graph snapshot plus song/artist/footer; 1600×1000 PNG; browser validates dimensions | Native copy/save; Windows share-target chooser absent |
| Passive screenshot companion | Explicit map export available | Opt-in Windows screenshot observation, delayed preview, cancel behavior and native share targets are absent |
| Focus, full screen, tray, single instance | Native full-screen Focus, hide-to-tray lifecycle, action forwarding and restore; native smoke harness exercises window lifecycle | Independent Full Screen action and Ctrl+F implemented. Mac Focus hides widgets/Stage Manager; no Windows shell-setting equivalent. Real tray-menu click still required |
| Desktop wallpaper | Separate display-only renderer attached to Explorer WorkerW, click-through, main-window restore on host loss | WorkerW is undocumented. Real Explorer restart, monitor/scaling/workspace changes and alternate shells remain acceptance gates |
| Player-only Beat Sync | WASAPI process-loopback, explicit PID selection and FFT, no mixed system-audio fallback | Two-stream isolation, process exits, routing changes, unsupported build and protected-audio silence need Windows 11 hardware tests; browser process tree can include several tabs |
| Global shortcuts | Opt-in RegisterHotKey bindings, conflicts reported, disable releases bindings; focused alternatives remain | Real conflict/enable/disable cycles and held keys need native runtime tests; per-binding persistent preferences differ from Mac |
| Battery/sleep/visibility scheduling | Windows power, lock/display and battery-saver events; shared lower battery rate; capture stops on pause/hidden/sleep | Physical suspend/resume and battery measurements; Mac thermal-pressure tiers are absent; previews are separately bounded to 15 Hz |
| Atomic local persistence and failure preservation | Windows MoveFileExW replace-existing storage; shared schema validation preserves invalid libraries; browser tests corrupt-library behavior | Installed save/relaunch, write-denial and disk-full recovery must pass; native smoke changes preference twice. Invalid-library sessions prevent writes but permit temporary edits, unlike Mac's blocked collection editor |
| Permissions and privacy | No player credentials, microphone capture, audio files or audio uploads; metadata goes only to enabled lyric services | Real OS denial/errors and player process selection need acceptance; see source and Windows usage guide |

## Release gate

Do not label this full Mac parity. Publish the actual Windows version/build requirement and remaining functions alongside any preview. A green package build proves compilation/packaging; it does not replace the real-player, audio-isolation, Explorer and physical-power checks above. Missing functions remain product work even after build and smoke checks pass.
